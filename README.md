# Online Store 🛒

## Description

This is a fully responsive single-page online shopping website built using HTML, CSS, and Bootstrap 5. It features a clean layout with product listings, categories, sales sections, customer reviews, and a modern design to simulate a real e-commerce platform.

The site is ideal for showcasing UI/UX design skills and front-end development with no backend logic. Buttons and forms are functional in layout but do not submit data, making it perfect for static portfolio display or future backend integration.
